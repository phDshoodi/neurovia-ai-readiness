Neurovia — Prototype Demo

This folder contains a responsive, static demo of the Neurovia prototype intended for hackathon presentation.

How to run locally:

1. From the repository root run a simple HTTP server (so that fetch can load knowledge files):

```bash
python3 -m http.server 8000
```

2. Open the demo in your browser:

http://localhost:8000/demo/index.html

Notes:
- This is an educational prototype only. The simulated EEG, risk indicators, and assistant responses are for demonstration purposes and are not clinically validated.
- Do not use this demo for real medical decision-making.
